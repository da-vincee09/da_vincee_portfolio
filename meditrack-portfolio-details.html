Project Overview

MediTrack is a mobile application designed to address the challenges of medication non-adherence by reminding users when to take their prescribed medicines. Built with Flutter for a seamless cross-platform experience, the app leverages modern backend and cloud technologies to ensure reliability, accessibility, and ease of use.

The app integrates features such as QR scanning for quick medicine tracking, a reminder system powered by Firebase, and inventory management tools to keep users aware of their medicine stock. With secure authentication and password reset handled via Node.js and Firebase, MediTrack provides both functionality and safety for its users.

Key Features

Smart Medicine Reminders

Push notifications via Firebase to remind users when to take their medicines on time.

QR Code Integration

Scan medicines using Flutter’s mobile QR functionality for quick and accurate tracking.

Inventory Management

Monitor medicine stock levels to avoid running out of essential prescriptions.

Secure Authentication

Firebase authentication for sign up/login and Node.js backend for password resets.
